# Функционалности за офериране — BCC 95

Документът описва всички функционалности за **офериране/оферти**, разработени в системата BCC 95, заедно с прогнозни часове за изработка и обосновка защо всяка функционалност е необходима.

> Часовете са оценка на **професионалната разработка** (проектиране + изработка + тестване), т.е. колко би струвало да се изгради функционалността, а не реалното време, прекарано с AI-асистенция. Приема се един full-stack разработчик със средно/старши опит.
